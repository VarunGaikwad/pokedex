# Meadow Route scenery

`route-day.svg` and `route-night.svg` are original pixel-art panoramas created for this Pokédex interface. All geometry, route layout, tiles, houses, trees, flowers, water, mountains, and palettes were drawn specifically for this project; no game maps, screenshots, sprites, or third-party scenery assets were traced or copied.

The scene evokes handheld-era tile-based adventure games using crisp integer coordinates and reusable SVG symbols. Both files are self-contained (no fonts, scripts, external images, or network requests). The night version shares the original route geometry with a separate forest/navy palette, illuminated windows, stars, and a crescent moon.

Pokémon character artwork displayed separately in the interface is supplied by the existing PokéAPI sprites repository and is not part of these original scenery files. Pokémon remains the property of its respective rights holders. This is an unofficial fan project.
